# On Generalized Mersenne Primes in Real Quadratic Fields

## Overview
This repository contains the undergraduate graduation research project focused on extending the concept of Mersenne primes to real quadratic fields. The study explores abstract algebraic structures, prime element analogues, and underlying mathematical proofs within quadratic number rings.

## Tools & Technologies Used
* LaTeX : Used for writing, structuring, and formatting the academic manuscript and presentation slides.
* Wolfram Mathematica: Utilized for computational verification, symbolic manipulation, and algorithmic analysis of prime candidates.

## Key Highlights
* Detailed mathematical proofs and structural analysis of generalized Mersenne numbers.
* High-quality academic typesetting using LaTeX.
